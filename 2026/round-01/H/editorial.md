# H · 一步之遥

[牛客原题](https://ac.nowcoder.com/acm/contest/143651/H) · [题面](problem.md)

## 解题思路

从左到右确定每一位，每次选择**能够填完剩余位置的最小数字**。位数相同时，第一处不同的数位越小，整个数就越小。

本题只需要循环、条件判断和几个整数变量，不使用数组。每确定一位就直接输出，因此也不需要保存最多 100 位的答案。

### 1. 先检查是否有解

$n$ 位正整数的数位和最小为 1，最大为 $9n$，并且这之间的每个整数和都能实现（证明见后文）。因此，若 $s>9n$，输出 `-1`。程序也检查了 $s<1$，虽然正式输入保证 $s\ge1$。

### 2. 按从小到大的顺序尝试当前数字

用 `remaining` 表示还没有填写的数位需要凑出的和，用 `previous` 保存前一位。

- 第一位从 1 到 9 尝试，不能有前导零。
- 其他位置从 0 到 9 尝试，但必须满足 `abs(d - previous) <= 1`。

### 3. 计算后面能凑出的最小和、最大和

假设当前选择数字 $d$，后面还有 $m$ 位。

为了让后面的和尽量小，每一步把数字减 1，降到 0 后保持为 0；为了尽量大，每一步加 1，升到 9 后保持为 9。

例如当前数字为 3，后面还有 4 位：

- 最小后缀是 `2100`，数位和为 3。
- 最大后缀是 `4567`，数位和为 22。

后面第 $j$ 位的下界是 $\max(0,d-j)$，上界是 $\min(9,d+j)$。分别累加得到 `low` 和 `high`。这两个极端后缀本身也满足相邻限制，因此上下界都能达到。

后缀能实现的数位和在这两个端点之间没有缺口，所以当前数字可选的充要条件为：

$$
\text{low}\le \text{remaining}-d\le\text{high}.
$$

选择第一个符合条件的数字，立即输出，并更新 `remaining` 和 `previous`。候选数字没有确定前，不改变 `remaining`，这样不需要失败后再减回来。

最后一位后面没有剩余位置，`low`、`high` 都为 0，因此只会选择恰好用完剩余数位和的数字。

## 正确性说明

### 为什么上下界之间没有缺口？

固定当前数字 $d$。把后面第 $j$ 位的上界记为 $u_j=\min(9,d+j)$。从最小合法后缀开始，重复下面的操作：在还没有达到各自上界的位置中，选择**当前数字最小**的一个位置，将它加 1。

这个操作始终合法：

- 所选位置还没到上界，加 1 后不会超过 9 或其上界。
- 加 1 只可能与一个比它小 1 的邻位产生冲突。假设存在这样的后缀邻位：相邻位置的上界最多相差 1，而所选位置尚未达到上界，所以这个更小的邻位也尚未达到自己的上界。这与我们选了“尚未到上界的位置中数字最小的一个”矛盾。
- 固定的前一位 $d$ 也不会阻止增加：若第一位已经比 $d$ 大 1，它就已经达到自己的上界，不会被选中。

因此，每次都能合法地让数位和增加 1，直到所有位置达到上界。于是从最小和到最大和之间的每个整数都能实现；后面没有位置时，可达和只有 0，同样成立。

### 为什么 $1\le s\le9n$ 都有解？

从 `100…0` 出发，只要还没有全变成 9，就选择尚未达到 9 的位置中数字最小的一位，将其加 1。若邻位小 1，它也小于 9，与所选数字最小矛盾。因此相邻限制始终满足，首位也不会变成 0。每次和增加 1，最终到达 `999…9`，所以 1 到 $9n$ 都可实现。

### 为什么得到的是最小答案？

初始检查通过后至少存在一个答案。每次选定数字时，区间判断保证剩余部分可以补全，因此之后总能继续选择，不会输出到一半才发现无解。

程序从小到大尝试，并选择第一个可以补全的数字。如果有更小的合法答案，在与程序输出首次不同的位置，它一定选择了一个更小且能够补全的数字；但这样的数字本应先被程序选中，产生矛盾。因此输出的就是最小答案。

## 复杂度分析

共有 $n$ 个位置，每个位置最多尝试 10 个数字，每次最多循环 $n$ 次计算上下界，时间复杂度为 $O(10n^2)$，也可写作 $O(n^2)$。$n\le100$，计算量足够小。

只使用若干整数变量，确定一位就输出一位，额外空间复杂度为 $O(1)$，无需数组、字符串或高精度整数。

## C 语言参考代码

[下载源文件](solution.c)

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int n, s;
    scanf("%d%d", &n, &s);
    if (s < 1 || s > 9 * n)
    {
        puts("-1");
        return 0;
    }

    int remaining = s;
    int previous = -1;
    for (int i = 1; i <= n; i++)
    {
        for (int d = (i == 1 ? 1 : 0); d <= 9; d++)
        {
            if (i > 1 && abs(d - previous) > 1)
                continue;

            int low = 0, high = 0;
            int smallest = d, largest = d;
            for (int k = i + 1; k <= n; k++)
            {
                if (smallest > 0) smallest--;
                if (largest < 9) largest++;
                low += smallest;
                high += largest;
            }

            int rest = remaining - d;
            if (low <= rest && rest <= high)
            {
                putchar('0' + d);
                remaining = rest;
                previous = d;
                break;
            }
        }
    }
    putchar('\n');
    return 0;
}
```

## 易错点

- 首位从 1 开始，后续位可以是 0。
- 当前候选数字必须与前一位相差不超过 1；代码显式检查这一条件，让实现与证明直接对应。
- `low`、`high` 只统计当前位后面的数位，不包含当前候选数字。
- 不能只证明上下界能达到，还要说明中间没有不可达的和。
- 候选确认可行后再更新剩余和，避免忘记撤销试探修改。
- 确定一位就输出一位，不要将完整答案存入整数；最后补上换行。
