# H · 一步之遥

[牛客原题](https://ac.nowcoder.com/acm/contest/143651/H)

时间限制：C/C++/Rust/Pascal 1秒，其他语言2秒  
空间限制：C/C++/Rust/Pascal 256 M，其他语言512 M  
 64bit IO Format: %lld

## 题目描述

给定两个整数 n 和 s，请构造一个正整数，满足以下全部条件：  
恰好有 n 位，首位不能为 0；  
所有数位之和恰好为 s；  
任意两个相邻数位之差的绝对值不超过 1。  
  
在所有满足条件的正整数中，输出数值最小的一个。如果不存在，输出 -1。

## 输入描述:

输入一行两个整数 n、s（1 ≤ n ≤ 100，1 ≤ s ≤ 900）。  
每个测试文件只有一组数据。

## 输出描述:

输出一行，表示满足要求的最小正整数；如果不存在，输出 -1。  
答案可能超过常见整数类型的表示范围。

示例1

## 输入

```
4 16
```

## 输出

```
3445
```

## 说明

```
3445 的数位和为 16，相邻数位差为 1、0、1。首位不超过 2 时，总和最多为 2+3+4+5=14；首位为 3、第二位不超过 3 时，总和最多为 3+3+4+5=15。所以最小答案以 34 开头，后两位的最小可行选择是 45。
```

示例2

## 输入

```
5 1
```

## 输出

```
10000
```

## 说明

```
首位不能为 0，而数位和只有 1，因此首位为 1，其余位都为 0。
```

示例3

## 输入

```
5 44
```

## 输出

```
89999
```

## 说明

```
首位不超过 7 时，数位和最多为 7+8+9+9+9=42。首位取 8 后，其余四位必须均为 9 才能达到 44，因此最小答案是 89999。
```

示例4

## 输入

```
5 46
```

## 输出

```
-1
```

## 说明

```
五位正整数的数位和最多为 45，无法达到 46。
```

## 备注:

以首位为 1 的四位数为例，在满足相邻数位之差的绝对值不超过 1 的条件下：

* 最小的数是 1000，数位和为 1。
* 最大的数是 1234，数位和为 10。

实际上，1 到 10 之间的每一个整数，都可以成为这类数的数位和。
