# F · 蜂巢

[牛客原题](https://ac.nowcoder.com/acm/contest/143651/F)

时间限制：C/C++/Rust/Pascal 1秒，其他语言2秒  
空间限制：C/C++/Rust/Pascal 256 M，其他语言512 M  
 64bit IO Format: %lld

## 题目描述

给定整数 n，请输出 n 个纵向排列、上下相接的六边形蜂巢。相邻两个六边形蜂巢共用一条水平边，共用边只输出一次。  
  
使用半角点号 . 表示背景位置。点号是必须输出的字符，不能用空格代替。  
  

```
...+---+
../.....\
.+.......+
..\...../
...+---+
```

多个六边形的连接方式见样例 2。

## 输入描述:

输入一行一个整数 n（1 ≤ n ≤ 100）。  
每个测试文件只有一组数据。

## 输出描述:

输出所要求的字符画，共 4n+1 行。  
图形只包含半角字符 .、+、-、/ 和 \。每一行的可见字符必须与要求一致，不要添加提示文字。

示例1

## 输入

```
1
```

## 输出

```
...+---+
../.....\
.+.......+
..\...../
...+---+
```

示例2

## 输入

```
2
```

## 输出

```
...+---+
../.....\
.+.......+
..\...../
...+---+
../.....\
.+.......+
..\...../
...+---+
```
