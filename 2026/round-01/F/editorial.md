# F · 蜂巢

[牛客原题](https://ac.nowcoder.com/acm/contest/143651/F) · [题面](problem.md)

## 解题思路

一个蜂巢有五行，但相邻蜂巢共用一条水平边。先输出第一条水平边 `...+---+`，然后每次添加一个蜂巢时，只输出剩余四行：

```text
../.....\
.+.......+
..\...../
...+---+
```

重复 $n$ 次即可，共输出 $1+4n$ 行。字符串中的反斜杠需要写成 `\\`，才能输出一个 `\`；点号则直接输出，不能替换为空格。

## 正确性说明

第一条水平边是第一个蜂巢的上边。每次输出四行，会在已有水平边下补出一个完整蜂巢，其下边又作为下一个蜂巢的上边。重复 n 次后，恰好有 n 个蜂巢，共用边只输出一次。

## 复杂度分析

每个蜂巢输出固定长度的四行，时间复杂度 $O(n)$，额外空间复杂度 $O(1)$。

## C 语言参考代码

[下载源文件](solution.c)

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int n;
    scanf("%d", &n);
    puts("...+---+");
    for (int i = 0; i < n; i++)
    {
        puts("../.....\\");
        puts(".+.......+");
        puts("..\\...../");
        puts("...+---+");
    }
    return 0;
}
```

[下载源文件](solution.cpp)

```cpp
#include <iostream>
#include <cstdlib>
using namespace std;

int main()
{
    int n;
    cin >> n;
    cout << "...+---+\n";
    for (int i = 0; i < n; i++)
    {
        cout << "../.....\\\n";
        cout << ".+.......+\n";
        cout << "..\\...../\n";
        cout << "...+---+\n";
    }
    return 0;
}
```

C 版本使用 C99 或更新标准编译，C++ 版本使用 C++11 或更新标准编译。

## 易错点

- 不要在循环中输出完整五行，否则会重复共用边。
- 反斜杠要转义，正斜杠不需要。
- 点号、每行长度和换行都必须与题面一致。
