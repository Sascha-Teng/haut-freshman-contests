# B · 雨山

[牛客原题](https://ac.nowcoder.com/acm/contest/143651/B)

时间限制：C/C++/Rust/Pascal 1秒，其他语言2秒  
空间限制：C/C++/Rust/Pascal 256 M，其他语言512 M  
 64bit IO Format: %lld

## 题目描述

> 风从远方来，撞上山，抬升，冷却，落下一场雨。雨停后，风继续走，山还湿着。

一座山脉可以看作由有限个整数高度点依次连接而成的折线。已知最左端高度为 a，最右端高度为 b，总起伏量为 s。总起伏量是所有相邻高度之差的绝对值之和。例如，高度依次为 3、8、2、6、5 时，总起伏量为 16。

  
一团初始含有 w 单位水汽的云，可以选择从左往右或者从右往左，沿选定方向穿过整座山脉。过程遵循以下规则：  
每累计上升 1 单位高度，消耗 1 单位水汽，降下 1 单位雨水；下降时不降雨，也不会补充水汽。水汽耗尽后，云仍继续穿行，但不再降雨。  
  
具体山形未知，只给出 a、b、s、w。保证 s≥|a-b|，且 s-|a-b| 为偶数，即这些信息能够对应一座合法山脉。  
  
请选择行进方向，求最多能降下多少单位雨水。本题只按上述规则计算。

## 输入描述:

输入一行四个整数 a、b、s、w。  
0 ≤ a,b,s,w ≤ 1000000000。  
保证 s ≥ |a-b|，且 s-|a-b| 为偶数。  
每个测试文件只有一组数据。

## 输出描述:

输出一个整数，表示最大降雨量。

示例1

## 输入

```
3 5 16 8
```

## 输出

```
8
```

## 说明

```
以高度 3→8→2→6→5 为例，从左往右累计上升 9，从右往左累计上升 7。初始水汽为 8，选择从左往右可降下 8 单位雨水。
```

示例2

## 输入

```
6 6 0 9
```

## 输出

```
0
```

## 说明

```
总起伏量为 0，云没有上升过程，降雨量为 0。
```
