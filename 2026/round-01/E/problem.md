# E · 回首

[牛客原题](https://ac.nowcoder.com/acm/contest/143651/E)

时间限制：C/C++/Rust/Pascal 1秒，其他语言2秒  
空间限制：C/C++/Rust/Pascal 256 M，其他语言512 M  
 64bit IO Format: %lld

## 题目描述

> 傍晚，沿着金水河畔的步道缓缓走着。
>
> 有时向前，有时回首。走过的路或许会再走一遍，但终究还是要抵达想去的地方。
>
> 如果途中恰好折返两次，这样的散步路线共有多少条？

一条笔直的步道上有 L+1 个整数位置，依次为 0,1,…,L。你从位置 s 出发，需要在恰好 T 分钟后到达位置 e。

每一分钟，你都必须向左或向右移动恰好 1 个单位，不能停留。在整个行走过程中，位置都必须在区间 [0,L] 内，不能越过步道的两端。

你需要恰好改变两次行走方向。一次方向改变，是指相邻两分钟的移动方向不同。因此，整条路线由三段方向不变的行走组成，每段都至少走一步；出发前或抵达后原地转身不计入方向改变次数。

请你求出符合上述条件的不同路线数。两条路线不同，当且仅当至少有某一分钟结束时，你所在的位置不同。

## 输入描述:

输入一行四个整数 L、s、e、T。  
2 ≤ L ≤ 500，0 ≤ s,e ≤ L，1 ≤ T ≤ 1000000000。  
每个测试文件只有一组数据。

## 输出描述:

输出一个整数，表示满足条件的不同路线数量。

示例1

## 输入

```
4 0 2 6
```

## 输出

```
2
```

## 说明

```
两条路线分别为 0→1→2→1→0→1→2，以及 0→1→2→3→2→1→2。它们均恰好改变两次方向。
```

示例2

## 输入

```
2 1 1 4
```

## 输出

```
2
```

## 说明

```
两条路线为 1→0→1→2→1 和 1→2→1→0→1。
```

示例3

## 输入

```
2 0 0 4
```

## 输出

```
0
```

## 说明

```
从 0 出发四步返回 0 的路线只有 0→1→0→1→0 和 0→1→2→1→0，分别改变三次和一次方向，都不满足要求。
```

## 备注:

由于整条路线恰好改变两次方向，因此可以用第一次折返的位置 $x$ 和第二次折返的位置 $y$ 来描述一条路线。  
  
例如，样例 1 中：  
  
- 路线 $0\to1\to2\to1\to0\to1\to2$，两次折返的位置分别为 $2$ 和 $0$。  
- 路线 $0\to1\to2\to3\to2\to1\to2$，两次折返的位置分别为 $3$ 和 $1$。  
  
注意，并不是任意两个位置都能构成合法路线，还需要满足题目中的时间、方向和边界限制。
