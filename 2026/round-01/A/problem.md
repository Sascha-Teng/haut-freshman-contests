# A · 寻室

[牛客原题](https://ac.nowcoder.com/acm/contest/143651/A)

时间限制：C/C++/Rust/Pascal 1秒，其他语言2秒  
空间限制：C/C++/Rust/Pascal 256 M，其他语言512 M  
 64bit IO Format: %lld

## 题目描述

> 那时候，每逢比赛，Sascha总要提前寻找一间合适的教室。
>
> 有的教室空着，却没有足够的插座；有的教室设施齐全，却早已有了人；好不容易找到一间空教室，又发现座位不够。
>
> 比赛即将开始，而我们需要的，只是一间教室。

为了参加比赛，你需要在一条走廊上找到合适的教室。  
  
一条走廊上有 $n$ 间教室，从左到右依次编号为 $1,2,\dots,n$，相邻两间教室之间的距离为 $1$。你目前位于编号为 $s$ 的教室门口。  
  
本次比赛共有 $p$ 名参赛者，并且需要至少 $q$ 个可用插座。第 $i$ 间教室有 $a_i$ 个座位、$b_i$ 个可用插座，占用状态为 $c_i$。其中，$c_i=0$ 表示空闲，$c_i=1$ 表示已被占用。  
  
只有空闲、座位数不少于 $p$、可用插座数不少于 $q$ 的教室才符合要求，即必须同时满足 $c_i=0$、$a_i\ge p$、$b_i\ge q$。  
  
请在所有符合要求的教室中，选择与你当前位置距离最小的一间。第 $i$ 间教室与你当前位置的距离为 $|i-s|$，其中 $|x|$ 表示 $x$ 的绝对值。如果有多间教室的距离相同，选择编号较小的一间。你当前所在的第 $s$ 间教室也可以选择，其距离为 $0$。  
  
如果没有符合要求的教室，输出 $-1$。

## 输入描述:

第一行输入四个整数 $n$、$s$、$p$、$q$。  
接下来 $n$ 行，第 $i$ 行输入三个整数 $a_i$、$b_i$、$c_i$，依次描述第 $i$ 间教室。  
  
$1 \le n \le 100000$，$1 \le s \le n$；  
$1 \le p,q \le 1000000$；  
$0 \le a_i,b_i \le 1000000$，$c_i$ 为 $0$ 或 $1$。  
每个测试文件只有一组数据。

## 输出描述:

输出一个整数，表示所选教室的编号。如果没有合适的教室，输出 -1。

示例1

## 输入

```
6 3 5 2
8 4 0
5 1 0
9 6 1
2 7 0
5 2 0
20 8 1
```

## 输出

```
1
```

## 说明

```
第 1 间和第 5 间教室均满足条件，与第 3 间的距离都为 2，因此选择编号较小的第 1 间。第 3 间教室已被占用。
```

示例2

## 输入

```
4 2 6 3
5 7 0
6 2 0
10 4 1
6 3 1
```

## 输出

```
-1
```

## 说明

```
第 1 间座位不足，第 2 间插座不足，第 3、4 间已被占用，因此没有合适的教室。
```

示例3

## 输入

```
3 2 4 1
10 5 0
4 1 0
8 2 0
```

## 输出

```
2
```

## 说明

```
第 2 间教室满足条件，且就是当前位置，距离为 0。
```
