# A · 寻室

[牛客原题](https://ac.nowcoder.com/acm/contest/143651/A) · [题面](problem.md)

## 解题思路

题目要求我们找到一间满足条件、距离最近的教室，如果距离相同，则选择编号较小的教室。

可以按编号从小到大，依次检查每间教室。

第 $i$ 间教室符合要求，当且仅当以下三个条件同时成立：

- $a_i \ge p$：座位足够。
- $b_i \ge q$：可用插座足够。
- $c_i = 0$：教室空闲。

对于符合要求的教室，计算它与当前位置的距离：

$$
d = |i-s|
$$

用 `ans` 记录目前选中的教室编号，用 `minDist` 记录对应的距离。如果当前教室的距离更小，就更新答案。

因为我们按照编号从小到大的顺序遍历，先找到的教室编号一定更小。因此，只有在 `d < minDist` 时才更新答案；距离相等时保留原答案，即可满足题目要求。

初始化 `ans = -1`。如果始终没有符合要求的教室，最终自然输出 `-1`。将 `minDist` 初始化为 `n`，比任意两间教室的距离都大，可以保证第一间符合要求的教室被选中。

每间教室的信息读入后就可以立即判断，不需要使用数组保存。

## 正确性说明

遍历过程中，我们只考虑同时满足三个条件的教室，因此记录的教室一定符合要求。

遇到距离更小的教室时更新答案，保证记录的始终是已经检查过的合适教室中的最小距离；距离相等时保留先遇到的教室，保证编号最小。

遍历结束后，所有教室都已被检查，所以得到的就是题目要求的答案。如果没有合适的教室，答案保持为 `-1`。

## 复杂度分析

每间教室只检查一次，时间复杂度为 $O(n)$。

只使用若干变量，额外空间复杂度为 $O(1)$。

## C 语言参考代码

[下载源文件](solution.c)

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int n, s, p, q;
    scanf("%d%d%d%d", &n, &s, &p, &q);

    int ans = -1;
    int minDist = n;  /* 任意两间教室的距离最多为 n - 1 */

    for (int i = 1; i <= n; i++)
    {
        int a, b, c;
        scanf("%d%d%d", &a, &b, &c);

        if (a >= p && b >= q && c == 0)
        {
            int d = abs(i - s);

            if (d < minDist)
            {
                minDist = d;
                ans = i;
            }
        }
    }

    printf("%d\n", ans);
    return 0;
}
```

`abs()` 用于求整数的绝对值，在 C 语言中需要包含头文件 `<stdlib.h>`。上述代码使用 C99 或更新标准编译。


## 易错点

- 三个条件必须同时满足，应该使用 `&&`。
- 更新条件应为 `<`，写成 `<=` 会在距离相同时选中编号更大的教室。
- 当前所在的第 $s$ 间教室也可以选择，距离为 $0$。
- 最后输出的是教室编号，不是距离。
