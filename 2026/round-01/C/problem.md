# C · 藤萱

[牛客原题](https://ac.nowcoder.com/acm/contest/143651/C)

时间限制：C/C++/Rust/Pascal 1秒，其他语言2秒  
空间限制：C/C++/Rust/Pascal 256 M，其他语言512 M  
 64bit IO Format: %lld

## 题目描述

有 r 朵红花和 y 朵黄花。你可以任意调整顺序，将所有花朵排成一个首尾相接的花环。  
  
每对相邻花朵中，若颜色不同，贡献 1 点美丽值；若颜色相同，贡献 0 点美丽值。第一朵与最后一朵也相邻，每对相邻花朵只计算一次。  
  
花朵总数至少为 3，允许其中一种颜色的花朵数量为 0。请问花环的最大美丽值是多少？

## 输入描述:

输入一行两个整数 r、y（0 ≤ r,y ≤ 1000000000，r+y ≥ 3）。  
每个测试文件只有一组数据。

## 输出描述:

输出一个整数，表示花环的最大美丽值。

示例1

## 输入

```
5 3
```

## 输出

```
6
```

## 说明

```
按红、黄、红、黄、红、黄、红、红的顺序围成一圈，可以得到 6 点美丽值。
```

示例2

## 输入

```
4 4
```

## 输出

```
8
```

## 说明

```
让红花和黄花完全交替，8 对相邻花朵均为异色。
```

示例3

## 输入

```
3 0
```

## 输出

```
0
```

## 说明

```
只有红花，任意相邻花朵都是同色，美丽值为 0。
```
