# G · 红雨

[牛客原题](https://ac.nowcoder.com/acm/contest/143651/G)

时间限制：C/C++/Rust/Pascal 1秒，其他语言2秒  
空间限制：C/C++/Rust/Pascal 256 M，其他语言512 M  
 64bit IO Format: %lld

## 题目描述

一场红雨持续 2n-1 分钟。各分钟的雨滴数量依次为：  
1，2，…，n-1，n，n-1，…，2，1。  
当 n=1 时，整场雨只有 1 分钟，落下 1 滴雨。  
  
给定正整数 k，只在每个完整分钟结束时统计累计雨滴数。请问最早在第几分钟结束时，累计雨滴数达到或超过 k？  
如果直到雨结束，累计雨滴数仍小于 k，输出 -1。

## 输入描述:

输入一行两个整数 n、k（1 ≤ n ≤ 100000，1 ≤ k ≤ 1000000000000）。  
每个测试文件只有一组数据。

## 输出描述:

输出一个整数，表示最早满足条件的分钟数。如果整场雨的总雨滴数不足 k，输出 -1。

示例1

## 输入

```
4 12
```

## 输出

```
5
```

## 说明

```
各分钟雨滴数为 1、2、3、4、3、2、1。第 4 分钟结束时累计 10 滴，第 5 分钟结束时累计 13 滴，因此答案为 5。
```

示例2

## 输入

```
3 10
```

## 输出

```
-1
```

## 说明

```
整场雨共 9 滴，无法达到 10 滴。
```

示例3

## 输入

```
5 1
```

## 输出

```
1
```

## 说明

```
第 1 分钟结束时已有 1 滴雨。
```

## 备注:

本题的部分输入数据及累计雨滴数可能超出 32 位有符号整数的表示范围，请使用足够大的整数类型进行存储和计算。
